# テスト計画

- 方針：pytestで、APIキーと通信なしで毎回実行できるテストをP0の中心にする（設計書9.4）。通信を使うテストは `@pytest.mark.network` を付け、既定では実行しない。
- 期待値は、テストを書く人が合成データから手で計算して書く。実装の出力を期待値にしない（設計書7.7）。
- 開発中は、通常のClaude Codeのセッションからテストを動かしてよい（設計書9.4）。
