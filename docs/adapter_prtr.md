## 2. ファイルの形【確認済み】

- ZIP の中は、フォルダー1つと、テキストのファイル1つ（`本紙/本紙.txt`、`別紙/別紙.txt`、`他業種/他業種.txt`。一括は `全体/` の下に3つ）。エントリの名前は UTF-8 の印のない Shift JIS。
- 文字コードは Shift JIS（cp932 で全行を読めた。BOM なし）。項目は `"` で囲み、`,` で区切る。行の区切りは CR＋LF（構成の説明のⅡと、ファイルで確かめた）。
- **見出しの行はない**。構成の説明は列の名前を「本紙_TITLE.txt」などで参照せよとするが、取得した ZIP（一括を含む）には、そのファイルがない。列は構成の説明の番号（1から）で特定する。
- 列の数はすべての行で同じ：本紙23、別紙41、他業種3。
- 文字の範囲は JIS X0201・JIS X0208 で、範囲外の文字は似た文字か片仮名の読みに置き換えている（構成の説明の注2）。

## 5. 年度（U9）

- 本紙の2列目「排出年度」は、令和6年度把握のファイルでは全行が `2024`、令和5年度把握のファイルでは全行が `2023` だった。公表ページの「把握年度 令和6年度」は排出年度2024（令和6年度）の排出量・移動量で、届出はその翌年度、公表は令和8年2月【確認済み：ファイルと公表ページ】。年度は排出年度で呼び、`fiscal_year` に入れる。
- 法人番号（本紙12列）は、構成の説明が「２０２３年度から追加された項目」とし、令和5年度把握（排出年度2023）のファイルにある。排出年度2022以前のファイルにあるかは確かめていない。
- 対象物質の見直し：化管法施行令の改正（令和3年10月20日公布、令和5年4月1日施行）で、第一種指定化学物質は462物質から515物質になり、「改正後の対象物質の排出・移動量の把握は令和５年度から、届出は令和６年度から実施」（環境省の報道発表）。別紙の4列目（管理番号）も「２０２３年度から変更された項目」。**排出年度2022と2023の間の比較は、見直しをまたぐ**ので、比較の条件を確定できない（`substance_list_revision`）。排出年度2023と2024の比較は、またがない。

## 6. 比較の単位と、年度間の対応

- 比較の単位：事業所×物質（管理番号）×排出先×年度（設計書8.4）。
- 年度の中：本紙と別紙を、年度＋整理番号で結ぶ（別紙から本紙へは多対1。本紙の1行が別紙の複数行に対応するので、本紙の値を別紙の行の数だけ数えない）。他業種は結ばない（1対多で、量を二重に数えるため）。
- 年度の間：**整理番号では結ばない**。令和5・6年度で同じ整理番号は1つもなかった【確認済み】。構成の説明にも、年度をまたいで同じ事業所を指すとは書かれていない。
- 骨組みの対応のキー：法人番号・都道府県・市区町村・主たる業種コードの組。法人番号・都道府県・市区町村の組だけでは、令和6年度の 4,069 組、令和5年度の 4,050 組に事業所が2つ以上あった【確認済み】。キーに当たる事業所がどちらかの年度で2つ以上あれば、同じ事業所と決められないので比べない（候補は作らず、比較できない組として数える）。法人番号が空欄の事業所は、年度間を結ばない。
- 片方の年度にだけある事業所・物質を「新規」「廃止」と書かない（届出の閾値・対象の変更・届出漏れ・対応の不明がありうる）。
- 対応表 `prtr_facility_matches`（10章）は、キーで結べない事業所を、記者と Claude が事業所名・所在地などの資料で確かめて結ぶためのもの。骨組みでは表の定義だけを作り、検出SQLは使わない。

## 7. 比較のルールと、禁止する推論

- 物質ごとに比べ、毒性の異なる物質を重さで合計しない。単位（kg と mg-TEQ）を混ぜない（キーに単位を入れる）。
- 大気・公共用水域・土壌・埋立を区別する。下水道・事業所の外への移動を、環境への排出と合算しない。
- 届出の値の変化として書く。排出量の変化から、健康被害、実際の曝露、違法性を推定しない（設計書8.4の禁止する推論）。
- 見かけの変化の候補：対象物質の見直し（5章）、届出の閾値、届出対象外の事業所の欠落、単位の誤り、届出の訂正（修正版の差し替え）。

## 9. 原本照合

PRTR には別の形式（PDF）がないので、内閣府の T6b（CSV と PDF の照合）は対象外（`reconcile.source_check: none`）。代わりに、設計書8.4のとおり、ZIP の中のテキストを別の読み込み処理で読み直す再集計（V3b）と、本紙・別紙の整理番号の対応の検査（PQ04・PQ05）で行う。

見出しの行がないので、内閣府の別経路の読み込み（見出しの文字列で列を探す）は使えない。列の番号で読むことになり、正規化の経路と同じ列の番号に頼る（列のずれは、列の数の検査 PQ01 と、値の形の検査で見つける）。どう独立させるかは13章の未決。

## 10. 型付きの表と対応表（`datasets/prtr/tables.sql`）

共通の8表（`records` など）に加えて、次の3表を置く。値の列は原単位のまま、量は十進数の文字列。

- `prtr_facilities`：本紙。1行が1事業所・1年度。`record_id`（`records` への外部キー）、`record_status`、`fiscal_year`、`seiri_no`、`corp_number`（13桁か NULL）、`pref`、`city`、`industry_code`、`industry_name`、`substance_count`。（`fiscal_year`、`seiri_no`）は一意。
- `prtr_releases`：別紙。1行が1事業所・1物質・1年度。`record_id`、`record_status`、`fiscal_year`、`seiri_no`、`facility_record_id`（年度＋整理番号で結んだ本紙の行）、`sheet_no`、`substance_code`、`substance_name`、`unit`（`kg`・`mg-TEQ`）、`air`・`water`・`soil`・`landfill`（排出量）、`sewer`・`offsite`（移動量）、`incomparable_reasons_json`。（`fiscal_year`、`seiri_no`、`substance_code`）は一意。
- `prtr_facility_matches`：年度間の事業所の対応表。内閣府の `procurement_matches` と同じ列：`match_id`、`lead_id`、`left_json`・`right_json`（本紙の `record_id` の配列）、`relation`（`1:1`・`1:n`・`n:1`・`n:m`）、`reason`、`evidence_json`、`status`（`confirmed`・`pending`・`withdrawn`）、`created_at`。

## 11. 検出SQL（`screens/s1_air_release_change.sql`）

大気への排出量の変化（排出先は大気だけ。設計書8.4の「1排出先」）。共通の10列（実装仕様4.8）を返す。

- パラメーター：`:year_from`・`:year_to`（比べる2年度）に加えて、最初の範囲の `:pref`（都道府県）と `:substance_code`（管理番号）。値は `dataset.yaml` の `first_scope` に、結果を見る前に記者が決めて書く（設計書8.4。13章の未決）。CLI はまだこの2つを渡さない。
- 対象：両年度とも、6章のキー（法人番号・都道府県・市区町村・業種コード）に当たる事業所がちょうど1つで、その物質の行が両年度にあるもの。キー＋管理番号＋単位を `lead_key` にする。
- 両年度の `air` が十進数として異なる行だけを候補にする。比べるのは、kizashi が台帳の接続に登録する `decimal_cmp`（Decimal で比べる。REAL にしない。D-081）。十進数として読めない値は黙って落とさず、`excluded_*`（理由 `air_not_decimal`）にして `air_release_incomparable` の候補にする。`change_category` は `air_release_up`・`air_release_down`（メモの値は CLI が Decimal で計算し直す。内閣府の S1 と同じ）。片方の年度の `air` が空欄なら `air_release_incomparable`（理由 `air_missing_one_side`）。
- `metric` は `air_sum`、`row_refs_*` は別紙の行（キーに当たる事業所が1つなので、各年度1行）。大気の値が空の行は `excluded_*`（理由 `air_missing`）。
- `incomparable_reasons`：比べる2年度が対象物質の見直しをまたぐ（`:year_from` が2022以前で `:year_to` が2023以降）なら `substance_list_revision`。行の `incomparable_reasons_json` は CLI が合わせる（4.8）。
