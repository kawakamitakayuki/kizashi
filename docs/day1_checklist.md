## 2. PDFの抽出と照合の試験（U13・A6）

**手順**（開発のセッションで、Claude Codeに頼む。実装プロンプトの P0-1）：

1. 令和6・7年度の競争入札と随意契約のPDFを取得する（4本）。
2. `pdfplumber` で、レイアウトを保ったページ別テキストと、文字の座標を取り出す。
3. 各PDFから20件を抜き出し、アダプタ仕様7.2の行の対応と、7.3の項目の照合（方法(a)座標で列を切り出す、方法(b)行を順に見て全文を取り除く）を試す。
4. 照合する値を1文字変えた変異と、金額の変異（先頭に1桁足す、末尾の1桁を変える）を作り、どれも `match` にならないかを確かめる。

**判定**：

- 行の対応が取れ、件名・理由の照合が95%以上の件で `match` になり、変異が1件も `match` にならず、変えていない値が1件も `mismatch` にならず、金額の変異がすべて `mismatch` なら合格（アダプタ仕様7.3の基準）。方法(a)と(b)のうち、合格したほう（両方なら単純なほう）を採る。
- `pdfplumber` で崩れる場合は `pypdfium2` を試す。
- 随意契約で合格しなければ、方式・理由の候補は保留とし、比較成立のデモは金額の変化で組む（設計書7.5）。

**結果**（2026-11-05）：方法(a)が合格し、方法(b)は不合格だった。pdfplumber 0.11.10 と方法(a)に決め、随意契約の候補も保留にしない（`decisions.md` の D-002・D-003。4の結果は D-005）。

## 3. 理由を調べる資料の経路（A7・X1）

1. 令和6・7年度の両方にある同種業務の候補を、合成ではなく実データから3つほど選ぶ（手作業の `query` 相当でよい）。
2. それぞれについて、入札公告・仕様書が内閣府のサイトで今も取れるかを探す。取れなければ、契約公表の注記、随意契約の理由、調達ポータルの調達公告（D073）、行政事業レビューシート（D059）で代えられるかを見る。

**判定**：1件でも理由をたどれる資料が見つかれば合格。見つからなければ、デモを見かけの変化と保留を中心にする（設計書X1）。
